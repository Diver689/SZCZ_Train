# 苏州 ↔ 常州 列车时刻表

苏州/苏州园区 ↔ 常州 的高铁、动车、普速列车时刻查询工具，单文件 HTML，开箱即用。

## ✨ 功能特性

### 🚄 列车查询
- **双向时刻** — 苏州→常州、常州→苏州一键切换
- **园区线支持** — 苏州园区站往返常州独立方向
- **316 趟车次** — 覆盖日常线、周末线、高峰线
- **多维度筛选** — 出发时段、车型、历时、坐席、站点全方位过滤

### 🎫 余票与票价
- **实时余票** — 接入 12306 官方数据，各席别库存一目了然
- **票价显示** — 商务座/一等座/二等座/硬卧/软卧/硬座精准展示
- **购票入口** — 列表行一键跳转 12306 App 或网页版

### 📍 路线与导航
- **经停站查询** — 点击车次查看完整经停站与时刻表
- **高德导航** — 公交/地铁/驾车一键规划到车站路线
- **车站位置** — 苏州站、苏州园区站、常州站原生 POI

### 🎨 界面
- **浅色 / 深色** 双模式
- **响应式布局** — 适配桌面与移动端
- **置顶导航栏** — 方向切换 + 日期选择 + 站点直达
- **收藏车次** — 常用车次一键收藏，快速查看

## 🚀 使用方法

直接用浏览器打开 `苏州到常州列车时刻表.html` 即可，无需任何安装。

所有数据（收藏、设置）保存在浏览器本地。

## 📊 数据说明

| 线路 | 站点 | 车次 |
|------|------|------|
| 苏州 → 常州 | 苏州站(SZH) → 常州站(CZH) | ~142 趟 |
| 常州 → 苏州 | 常州站(CZH) → 苏州站(SZH) | ~152 趟 |
| 苏州园区 → 常州 | 苏州园区站(SIP) → 常州站(CZH) | ~11 趟 |
| 常州 → 苏州园区 | 常州站(CZH) → 苏州园区站(SIP) | ~11 趟 |

**数据来源**：12306 官方接口，月度自动维护更新

**车型**：G 高铁 / D 动车 / Z 直达 / T 特快 / K 快速

## 🛠 技术说明

- 纯前端单文件 HTML，零依赖
- 内置静态车次数据，离线可用
- 余票查询走 12306 官方接口（需联网）
- 车站导航使用高德地图 URI
- 数据常量：`TRAIN_DATA.sz` / `TRAIN_DATA.cz` / `TRAIN_DATA.sip` / `TRAIN_DATA.czsip`
- 车型数据：`TRAIN_MODELS`
